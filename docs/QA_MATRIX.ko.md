## 자동 검증

CI는 모든 PR에 대해 Windows·macOS·Linux에서 restore, build, 단위 테스트,
`dotnet format --verify-no-changes`를 실행합니다. 테스트는 140개이며 다음을 커버합니다.

- 경로 매핑/마이그레이션 및 런처별 디렉터리 분리.
- 설정 트랜잭션(검증 후 변경, 원자적 쓰기, 스키마 버전).
- 매니페스트 검증과 단계적 업데이트: HTTPS, SHA-256 재검증, 아카이브 경로 탈출, 아카이브
  한도, 취소, 드롭인 보존.
- 모드로더 선택, Java 탐색/검증/팩토리 정책, `RamCalculator` 기반 RAM 정책.
- 서버 상태 파싱과 백오프, 멀티플레이 목록(`servers.dat`) 기록기(수정 UTF-8 왕복 및 병합
  보존 포함).
- `options.txt` 대상 편집과 리소스팩 순서.
- 콘텐츠 탭 동작: 모든 `OptionsEditStatus` 분기가 사용자에게 전달되고, 서버 필수 팩은 이동·
  비활성화 시 예외 대신 메시지를 내며, 선택형 모듈 토글이 하위로 연쇄되고 저장되며, 매니페스트
  조회 실패가 미처리 예외가 아니라 메시지가 됨.
- 인증 오류 매핑: 마인크래프트가 반환하는 403을, 라이브러리가 `StatusCode`를 채우든 메시지에만
  넣든 인식.
- 로그아웃: 세션이 해제되고 주 버튼이 로그인으로 되돌아가며, 자격 증명 삭제가 예외를 던져도
  세션은 그대로 해제됨.
- 매니페스트 도구: 해시, 병합 보존, 의미 기반 diff, URL 템플릿, 도구 창의 검증/기본값/변경
  내역.

이들은 fake와 임시 파일을 쓰는 격리된 테스트이며, 실제 end-to-end 실행은 아닙니다.

## 수동으로 확인함

- 클라이언트 ID가 마인크래프트 API 승인을 받은 뒤, 실제 계정으로 Microsoft 로그인 전 과정
  (브라우저 방식). 승인 전 403 경로와 화면 메시지도 함께 관찰함.
- 런처·설정 창이 Windows에서 렌더링·동작함.

## 자동화 미포함

리소스팩 드래그앤드롭 순서 변경은 포인터·`DragDrop` 이벤트로 구동되어 수동으로만 확인합니다.
▲▼ 버튼은 단위 테스트된 동일한 `MoveToAsync` 진입점을 호출하므로, 제스처 자체는 아니어도
순서 규칙은 커버됩니다.

## 수동 릴리스 게이트

| End-to-end 흐름 | Windows | macOS | Linux |
|---|---|---|---|
| 신규 설치 및 UI 렌더링 | 완료 | 필요 | 필요 |
| 로그인, 재시작, 세션 복원 | 완료 | 필요 | 필요 |
| Java 탐색/설치 및 모드 게임 실행 | 필요 | 필요 (x64 + arm64) | 필요 |
| Discord IPC 탐색 | 필요 | 필요 | 필요 (네이티브, Flatpak, Snap) |
| 배포 업데이트 / 취소 / 오프라인 폴백 | 필요 | 필요 | 필요 |
| 서명된 패키지 업데이트 | 필요 | 필요 + 공증 | 필요 |

공개 릴리스에는 실제 배포 엔드포인트 입력, 대상 OS 기기, 서명 자격 증명(Windows 인증서,
Apple Developer 서명/공증)이 아직 필요합니다. Iris와 OptiFine이 서로 다른 옵션 대상을 쓰므로,
셰이더 설정은 실제 모드팩으로 확인해야 합니다.
